01About

Between design and technology.

I’m a designer who writes production code. For eight years I’ve worked on both sides of product teams, so I know how a feature should work for the people using it and what it takes to build it well.

As a designer

Research, information architecture, interaction and UI design. I’ve run usability tests with patients, dispatchers and small-business owners.

As a developer

React and Angular apps in TypeScript, component libraries, API integration and testing. I care about the parts users never see.
