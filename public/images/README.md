# Images

Put your images here and reference them from `src/content/` with a path that starts at `/images/`:

```ts
portrait: { primary: '/images/portrait.jpg', alt: '/images/portrait-illustrated.png', ... }
images: { cover: '/images/loom/cover.jpg', hero: '/images/loom/hero.jpg' }
```

Suggested sizes:

- Portrait (both layers): 1200 × 1600, same framing so the lens reveal lines up
- Showcase cover: 1600 × 1200 (the first card is wider, 1600 × 820 works there)
- Case-study hero and final screens: 2400 × 1050
- Flows, IA, wireframes: 1200 × 900
- Components, design system, prototype: 1000 × 1000

Use JPG or WebP for photos and screenshots, PNG or SVG for illustrations.
